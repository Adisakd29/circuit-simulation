# โมเดลบอร์ด (GLB)

| ไฟล์ | ที่มา | ใบอนุญาต |
|---|---|---|
| `unoq.glb` | ดัดแปลงจากไฟล์ CAD ของ **Arduino UNO Q (ABX00162)** — `ABX00162-step.zip` (STEP แบบย่อ) และ `ABX00162-cad-files.zip` (Gerber, IPC-356) จาก <https://docs.arduino.cc/hardware/uno-q> | **CC BY-SA 4.0** (ตามไฟล์ `License.txt` ในชุด CAD ของผู้ผลิต) — ไฟล์ดัดแปลงนี้เผยแพร่ภายใต้ CC BY-SA 4.0 เช่นกัน |

สิ่งที่ดัดแปลง: แปลงเรขาคณิต STEP เป็นตาข่าย, สร้างเท็กซ์เจอร์ PCB จาก Gerber (ชั้นทองแดง/โซลเดอร์มาสก์), วางชิ้นส่วนตามแพดในไฟล์ IPC-356, สร้างรูปทรงหัวต่อ/พอร์ต/ชิปตามขนาดในเอกสาร, เพิ่มสกรีนตัวอักษร (ชื่อขา/ชื่อหัวต่อ) — **ตัดโลโก้และเครื่องหมายการค้าทั้งหมดออก** (ใบอนุญาต CC ไม่ครอบคลุมเครื่องหมายการค้า) · ชื่อรุ่นบนชิป (เช่น QRB2210, STM32U585) เป็นข้อความธรรมดาตามเอกสาร

สร้างใหม่: `scripts/models/build-unoq.sh` (ดาวน์โหลดไฟล์ CAD แล้วสร้างไฟล์นี้) — รายละเอียด `scripts/models/README.md`
